# Aurum
Interpreted Programming language made in C. 
If you're interested in learning how to make your own programming language, this is a pretty good place to start. The Aurum Standard provided a detailed description as to how interpreted languages work, and the processes of lexing, parsing, bytecoding, & execution.
In addition, Aurum is a lightweight (only 900-some kilobytes) language.

To be clear, Aurum is still an extremely WIP language, and it will get better as time goes on.

If you want more information as to the installation, syntax, and interpretation of Aurum, the Aurum Standard provides exactly that.
In addition, I have attached the LaTeX file that I used for the Aurum standard, for anyone that wants to make their own programming standard.
